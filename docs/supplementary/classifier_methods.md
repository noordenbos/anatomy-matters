# Molecular classifier implementations and feature handling

Implementation details for the four genomic and five transcriptomic classifiers applied to the discovery and institutional validation cohorts. The table identifies author software, reference-model adaptations and research reconstructions, with explicit handling of unavailable inputs. Hyperlinks identify the original methods and the versioned analysis code.

Code revision: [`v1.1.0`](https://github.com/noordenbos/anatomy-matters/tree/v1.1.0).

## A Genomic classifiers

Inputs comprise selected mutation events, per-case panel coverage and measured rearrangements by fluorescence in situ hybridization (FISH). Regional copy-number profiles are unavailable. A negative result is encoded as zero only where the corresponding feature was measured.

[Genomic classification notebook](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/genomic_classification_audit.ipynb)

| [HMRN](https://doi.org/10.1182/blood.2019003535)<br>Reference refit with research extension | Binary author-model features, including hotspots, rearrangements, mutation-or-deletion features and somatic hypermutation features. | The author reference is refitted with the recorded random-number settings, 1,000 starts and AIC selection. Frozen centers and priors reproduce six biological groups, including NEC. Prediction uses the highest posterior after marginalizing unobserved Bernoulli features. Unmeasured deletions and incompletely assessed hypermutation are not negative. This missing-feature extension is a research adaptation; no measured features yields Unassigned. | [Notebook section 4](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/genomic_classification_audit.ipynb)<br>[Reference fit](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/tools/classification_audit/fit_hmrn.R)<br>[Feature likelihood](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/dlbcl/genomic_classification_audit.py#L52) |

Missing inputs remain numeric NA and native PAM uses available-feature distances, without imputation. Others is the residual class. Exhaustive missing-input completions annotate sensitivity without vetoing the native call. Source availability and model output are separate: cases without reproducible genomic inputs remain unknown; Other, Others and NEC are classifier outputs. Panel-specific input masks are exported. The validation-wide BLYMFv2 panel designation is a provisional coverage assumption.

AIC, Akaike information criterion; CN, copy number; NEC, not elsewhere classified; PAM, partitioning around medoids. Native LymphPlex execution requires measured TP53 and, for TP53-negative cases, at least one measured center feature; this safeguard is not a validated minimum coverage requirement.

## B Transcriptomic classifiers

Inputs are normalized NanoString log2 matrices. Validation raw counts undergo positive-control scaling and housekeeping centering, without negative-control subtraction; discovery starts from its supplied normalized matrix. Gene symbols are harmonized and duplicate mappings averaged on the log scale.

[Transcriptomic classification notebook](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/transcriptomic_classification_audit.ipynb)

| Classifier and implementation | Inputs | Assignment and unavailable features | Analysis code |
|---|---|---|---|
| [LymphoMAP](https://doi.org/10.1016/j.ccell.2025.06.002)<br>Author package with panel-restricted features | Available genes shared with the LymphoMapR reference; 50 features selected per archetype within that overlap. | Native reference feature selection, ComBat adjustment and naive Bayes inference are retained. The already-log input branch is used for normalized NanoString log ratios, an explicit cross-platform choice. The posterior cutoff is 0, yielding best-match calls. The feature budget is a run setting, not a universal minimum panel requirement; actual selected genes are exported. | [Notebook section 2](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/transcriptomic_classification_audit.ipynb)<br>[Run settings](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/config/classification_audit/default.json)<br>[Author package](https://github.com/Green-Lab-MDACC/LymphoMapR) |
| [EcoTyper](https://doi.org/10.1016/j.ccell.2021.08.011)<br>Author lymphoma recovery workflow | Normalized expression for available lymphoma-reference genes; cell-state and ecotype reference models. | Native recovery scales genes within the query cohort and fills absent reference genes with zero. Ecotype calls require the native assignment rule: BH-adjusted assignment q < 0.25 and assignment to an ecotype-associated cell state. Otherwise the output is Unassigned. Maximum-abundance labels and B-cell state summaries are stored separately; abundance is not a posterior probability. | [Notebook section 3](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/transcriptomic_classification_audit.ipynb)<br>[Resource hashes](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/config/classification_audit/resource_manifest.json)<br>[Author recovery](https://github.com/digitalcytometry/ecotyper) |

Signature overlap is reported; absent pathway genes contribute zero. | Author median scaling and clipping precede Louvain clustering with an explicit threshold search. Cluster profiles receive the highest-correlated published subtype centroid from panel-restricted Schmitz, Morin and Li references; many-to-one naming is allowed. This cohort-dependent reconstruction does not use the authors’ trained KNN classifier and need not recover all four published groups. | [Notebook section 4](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/transcriptomic_classification_audit.ipynb)<br>[Louvain selection](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/dlbcl/rna_clustering_benchmark.py#L63)<br>[Label centroids](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/config/classification_audit/kotlov_reference_centroids.csv) |
| [Ciavarella](https://doi.org/10.1093/annonc/mdy450)<br>Clustering reconstruction | All 45 signature genes on the normalized log2 scale, without additional per-gene standardization. | Euclidean/Ward hierarchical clustering is cut into three groups, ordered by mean signature expression and named Hot, Intermediate and Cold. Intermediate is a biological expression group, not a missing or uncertain call. | [Notebook section 4](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/transcriptomic_classification_audit.ipynb)<br>[Ward partition](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/dlbcl/rna_clustering_benchmark.py#L32)<br>[Signature genes](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/config/classification_audit/clustering_features.csv) |
| [COO Lymph2Cx](https://doi.org/10.1182/blood-2013-11-536433)<br>Empirical research reconstruction | 15 predictor genes and five housekeeping genes; fixed public-patent coefficients after log2 housekeeping centering. All 20 genes are required. | Borders calibrated on 170 external NanoString profiles (GSE178394) define GCB (score < 715.4653), UNC (715.4653 ≤ score < 1249.5757) and ABC (score ≥ 1249.5757); values here are rounded. UNC is a valid output. This research reconstruction lacks proprietary gene-specific codeset calibration. Full-precision borders are supplied and are not transferred automatically to RNA-seq or microarrays. | [Notebook section 5](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/notebooks/transcriptomic_classification_audit.ipynb)<br>[Model and borders](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/config/classification_audit/lymph2cx_full.json)<br>[Coefficient source](https://github.com/noordenbos/anatomy-matters/blob/v1.1.0/config/lymph2cx_patent_research.json) |

The two cohorts are processed separately. Cohort-dependent scaling, batch adjustment or clustering can change calls when the query population changes. RNA-seq and microarray benchmark inputs use explicit platform-specific preprocessing rather than an assumed common measurement scale.

BH, Benjamini–Hochberg; COO, cell of origin; GCB, germinal-center B-cell-like; ABC, activated B-cell-like; UNC, unclassified; ssGSEA, single-sample gene set enrichment analysis; KNN, k-nearest neighbors.
